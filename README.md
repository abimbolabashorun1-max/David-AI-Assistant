# David AI Assistant

A real-time voice AI assistant inspired by Jarvis from Iron Man — a classy,
sarcastic butler that responds to voice commands using Google's Gemini
Realtime API and LiveKit Agents.

## Features
- Real-time voice interaction with low latency
- Persona-driven responses ("David" — butler with personality)
- Enhanced noise cancellation (LiveKit BVC)
- Async Python architecture

## Tech Stack
- **Python 3.x** (async/await)
- **LiveKit Agents** — real-time voice framework
- **Google Gemini Realtime API** — LLM + voice synthesis
- **Charon voice model**
- **Python-dotenv** — environment configuration
